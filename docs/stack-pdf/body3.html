05

Ключевой принцип. Система — это один движок заявок с конфигурируемыми типами, а не набор независимых модулей. Тип заявки — это запись конфигурации: схема полей, маршрут согласования, правило доступа, флаги спецмодулей. Новый тип добавляется через админку и работает без единой правки кода ядра.

Ядро заявок
  • Динамическая форма по fields_schema
  • Маршруты с копированием этапов при подаче
  • Статусная машина из 10 статусов
  • Возврат на доработку без пересогласования
  • Автоэтапы по access_rule
  • Журнал событий по каждому переходу
Модуль ячеек
  • Поиск свободной ячейки FOR UPDATE SKIP LOCKED
  • Код получения из шести цифр, срок хранения
  • Подтверждение выдачи сотрудником
  • Драйвер замка через DI — задел под электронные
Бронирование мест
  • Блокировка строки периода — квота не превышается
  • Лист ожидания с позициями в очереди
  • Автоповышение при отмене чужой брони
  • Запрет пересекающихся броней
Документы и подпись
  • PDF из HTML-шаблона, A4, поля 20 мм
  • Загрузка подписанного скана
  • Реестр освобождённых с выгрузкой CSV
