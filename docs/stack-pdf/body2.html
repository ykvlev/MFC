Безопасность

Права — только на сервере. RolesGuard по роли, ApplicationAccessGuard по владению заявкой или участию подразделения в маршруте.

Файлы. Проверка расширения и магических байт, лимит размера, имя на диске — UUID, отдача только через контроллер.

Транзакции. Любая смена статуса — одна транзакция вместе с записью в журнал событий и созданием уведомления.

Журнал неизменяем. Роль приложения лишена UPDATE и DELETE на таблице event_log.
