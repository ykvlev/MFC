# Проверка настоящего Android-телефона

## Подготовлено 20 октября 2026

- Удалённая схема `mfc` содержит таблицы и начальные данные.
- Учебная часть и Студенческое МФЦ используются в начальных маршрутах.
- API на компьютере работает с `.env.remote`; локальная `.env` не заменяется.
- Подключение к учебной БД без TLS согласовано только для учебного проекта.
- Схема `project` не менялась. Интеграционные тесты на удалённой БД не запускать.

Запуск API из корня проекта:

```powershell
node scripts/start-remote-api.cjs
```

API использует существующие локальные настройки JWT, Redis и MinIO из `.env`,
а DATABASE_URL получает из игнорируемой `.env.remote`.
Файлы пока сохраняются в MinIO на компьютере: удалённая PostgreSQL сама
по себе не делает приложение автономным от компьютера.

## Телефон в одной Wi-Fi-сети

На момент проверки адрес компьютера: `192.168.3.45`.
При смене сети или адреса DHCP проверить его заново.

1. Если Windows блокирует вход, открыть PowerShell от администратора:

   ```powershell
   New-NetFirewallRule -DisplayName 'MFC API - local WiFi testing' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 3000 -LocalAddress 192.168.3.45 -RemoteAddress 192.168.3.0/24 -Profile Any
   ```

   Открывается только порт API для текущей локальной подсети, не PostgreSQL.
   После проверки правило можно убрать:

   ```powershell
   Remove-NetFirewallRule -DisplayName 'MFC API - local WiFi testing'
   ```

2. В браузере телефона открыть `http://192.168.3.45:3000/api/v1/health`.
   Должно быть `status: ok`, `checks.database: ok`.
   Если не открывается — проверить firewall, гостевую сеть и изоляцию клиентов роутера.
3. Установить свежую debug-сборку:
   `clients/android/app/build/outputs/apk/debug/app-debug.apk`.
4. На входе указать сервер `http://192.168.3.45:3000/api/v1`.
5. Демо-студент: `student1@student.local`, пароль `student12345`.

Не использовать демо-пароли или незашифрованные соединения с реальными
персональными данными. Компьютер должен оставаться включённым, с работающими
API и MinIO. Проверка с компьютера не заменяет проверку с самого телефона.

## Подтверждено с компьютера по LAN-адресу

Health, вход студента, каталог восьми типов, список заявок, слоты и уведомления
вернули HTTP 200 на API, подключённом к удалённой схеме `mfc`.
Добавление правила firewall без прав администратора отклонено Windows;
проверка с физического телефона ожидается от пользователя.
